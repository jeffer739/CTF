# CTF Writeups

A collection of write-ups from cybersecurity competitions, labs, and hands-on security practice.

## Focus areas

- Web application security
- Reconnaissance and enumeration
- Authentication and access-control testing
- Privilege escalation
- Linux security
- Vulnerability analysis
- Practical exploitation and post-exploitation

## Why this repository exists

These exercises are used to build practical penetration-testing skills and to document the reasoning behind security findings—not simply the final flag or solution.

Where appropriate, write-ups cover:

**Attack surface → methodology → vulnerability → impact → remediation → lessons learned**
